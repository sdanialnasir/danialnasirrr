# Aqua Energizer
Underwater stone-and-sand puzzle game for the browser (Three.js). 30 levels, phone + desktop, one self-contained HTML file.

- **Play:** open `dist/index.html` (or host the `dist/` folder anywhere static).
- **Start here:** `HANDOFF.md` (setup, commands, where things live, rules).
- **Working with an AI assistant:** paste `docs/AI_BRIEF.md` first (rules + a prioritised polish list), then your task.
- **Full design + engineering log:** `CLAUDE.md`.

Controls: arrows/WASD to swim, Z undo (when it appears), R restart, hold M for the map, P pause. Phone: drag anywhere to swim
(farther = faster), hold the map button to see the whole level.
