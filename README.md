# Aqua Energizer
Underwater stone-and-sand puzzle game for the browser (Three.js). 30 levels, phone + desktop.

- Play: open `dist/index.html` (or host the `dist/` folder anywhere static).
- Develop: edit `src/` and open `src/index.html`; build with `python tools/build.py`.
- Tests: see `CLAUDE.md`.

Controls: arrows/WASD to swim, Z undo, R restart, hold M for the map, P pause. Phone: drag anywhere to swim
(farther = faster), hold the map button to see the whole level.
