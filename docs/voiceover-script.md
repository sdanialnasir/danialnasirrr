# Aqua Energizer — voice-overs (ElevenLabs)

Everything is generated by **`make_voices.bat`** (project folder, Windows). It runs `tools/make_voices.ps1`, which reads every line
from **`tools/voices.json`** and writes `src/assets/vo/<id>.mp3`, then rebuilds the game (`python tools/build.py`) if Python is
installed. Missing clips are fine: the game just stays silent there (subtitles still show the film and tutorial text).

## Steps
1. Run `make_voices.bat`, paste your ElevenLabs API key (it can save it in `.elevenlabs-key`, which git ignores).
2. Choose **1) Audition**: the same sample line in every shortlisted voice lands in `voice-auditions/`. Listen on your phone.
3. Choose **2) Make all**, type the narrator and diver you liked (or press Enter for Lily / Jessica). Your picks are remembered in
   `tools/voices.picked.json`. Already-made lines are kept; **3)** remakes everything; **4)** redoes one line after you edit it.

Model: `eleven_v4` (falls back to `eleven_v3`, then `eleven_multilingual_v2` with the [tags] removed, if your account can't use it).
Words in **[brackets]** are audio tags that steer the delivery (whisper, giggle, excited…); they aren't spoken.

## The two voices
- **Narrator** — warm, gentle storyteller (intro film, tutorial, new worlds, Daily Dive, finale). Calm and smiling, like a bedtime legend.
- **Diver** — small, bright, playful (short reactions). One line at most every 6 s; pearl / near-miss / undo lines play only some of the
  time, so it stays cute instead of repetitive.

the spoken text (with tags) lives in `tools/voices.json`, so keep the two in step when you change wording.
